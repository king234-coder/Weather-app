
# 🌦️ Weather App with Dynamic Video Background

A modern weather web app that shows real-time weather data with **dynamic background videos** based on weather conditions.

## ✨ Features

- 🔍 Search any city worldwide
- 🌡️ Real-time temperature & weather data
- 📍 Location + country display
- 🕒 Live local time & date
- 🎥 Dynamic background videos (based on weather)
- 🌙 Day / Night detection
- ⚡ Fast & responsive UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Open-Meteo API
- Cloudinary (for video hosting)

## 🌐 Live Demo

(https://king234-coder.github.io/Weather-app/)
## ⚙️ How It Works

1. User enters a city name
2. App fetches coordinates using Open-Meteo Geocoding API
3. Weather data is fetched using Open-Meteo Forecast API
4. Weather type is detected (rain, clear, snow, etc.)
5. Corresponding **video background** is loaded from Cloudinary

## 🎥 Video Background System

Each weather condition loads a different video:

- ☀️ Clear → Sunny video
- 🌧️ Rain → Rain video
- 🌫️ Fog → Fog video
- ❄️ Snow → Snow video
- ⛈️ Thunderstorm → Storm video
